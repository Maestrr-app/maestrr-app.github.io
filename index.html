POUR COMMENCER

Choisissez votre machine.

Le setup se lance sur Windows. Il installe sur ce PC ou prépare un serveur distant par SSH.

PC Windows
Docker Desktop et WSL2. Le setup vérifie la machine et installe ce qui manque.
Serveur Linux
Debian ou Ubuntu 64 bits, accès SSH avec un compte root ou sudo. Docker est installé si besoin.
TrueNAS SCALE
Version 24.10 ou suivante. Maestrr devient une application native, dans Apps.

Le setup vérifie les prérequis et les droits, puis vous accompagne dans le choix des applications, des dossiers et des comptes.

Avant d'installer la bêta

Essayez-la d'abord sur une machine de test et gardez une sauvegarde de vos configurations.

Le setup n'est pas encore signé. Edge et Windows peuvent donc le bloquer :

  1. dans les téléchargements d'Edge, ouvrez le menu … du fichier, puis Conserver → Afficher plus → Conserver quand même ;
  2. au lancement, cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Avant de l'exécuter, comparez son empreinte SHA-256 avec celle des notes de version.
